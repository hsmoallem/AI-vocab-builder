## Features Included

### Authentication (Phase 4)
- **Google Sign-In** — one tap, uses device Google account
- **Anonymous** — skip login with warning about no cloud backup
- **Graceful fallback:** App never bricks — if Firebase unavailable, LoginScreen still shows, Google button explains why, "Continue without account" works normally
- **Auth gate:** Firebase init + auth state listener → routes to login or home
- **Cloud backup:** One-tap backup/restore all words to Firestore
- **Anonymous restrictions:** Backup/restore disabled, orange warning banner shown

### Core (Phases 1-3)
- **3-tab navigation:** Reader · Daily Phrases · My Words
- **Add word:** Enter any word → AI translates via DeepSeek
- **Multi-meaning translation:** Words with several meanings get separate entries with unique examples
- **German article detection:** `der`/`die`/`das` auto-detected and prepended
- **Sort & search:** Alphabetical or newest-first, live search
- **Swipe-to-delete:** With confirmation dialog

### Flashcards
- Tap to flip (word → translation + examples)
- Swipe left/right to navigate
- Progress bar showing position
- Auto-marks word as reviewed when flipped

### PDF Reader
- **Native file picker** (Android `ACTION_OPEN_DOCUMENT`) — zero external dependencies
- **Two views:** Formatted PDF rendering (via `flutter_pdfview`) + text extraction (via `syncfusion_flutter_pdf`)
- **Tap-to-add:** Select a word in the text view → Add Word dialog opens pre-filled
- **PDF ↔ Text toggle** with segmented button in toolbar
- Compatible with any PDF file

### Daily Phrases
- AI generates 5 practical phrases every day (DeepSeek)
- Tap circle to mark as memorized (visual checkmark + strikethrough)
- Progress counter (`3/5` → trophy when all done)
- **Save to My Words (📌):** Pin any phrase to word database for flashcard review
- **Regenerate (🔄):** Get 5 fresh AI phrases on demand (ignores daily cache)
- **Theme input:** Type a topic → AI generates context-specific phrases (e.g. "at the restaurant")
- Auto-refreshes on new day; old phrases not stored
- Default language: German (configurable)

### Text-to-Speech
- Native Android `TextToSpeech` via MethodChannel
- Speaker icons on word cards and daily phrases
- Zero external TTS packages, zero KGP warnings

## Tech Stack

| Category | Choice | Why |
|----------|--------|-----|
| **Database** | `sqflite` | Isar unmaintained, incompatible with modern Gradle/AGP |
| **State** | `provider` | Lightweight, no code-gen, Flutter-recommended |
| **Auth** | Firebase Auth | Google + Anonymous, zero server code |
| **Cloud DB** | Firestore | Per-user document store, free tier (1GB) |
| **AI** | DeepSeek `deepseek-chat` | $0.14/M tokens, JSON-native responses |
| **PDF rendering** | `flutter_pdfview` (Apache 2.0) | 2M+ pub.dev downloads, hardware accelerated |
| **PDF text** | `syncfusion_flutter_pdf` | Best text extraction, `any` constraint |
| **File picker** | Native `MethodChannel` | Eliminated `file_picker` package — source of all Gradle failures |
| **TTS** | Native Android `TextToSpeech` | Zero external deps, zero KGP warnings |
| **Daily phrases** | `shared_preferences` | Today-only data, no DB overhead |

## Issues We Hit & How We Fixed Them

### 1. Isar → sqflite migration
- **Problem:** Isar 3.1.0 is unmaintained and its generated code is incompatible with Android Gradle Plugin 9.x
- **Fix:** Replaced with `sqflite` — mature SQLite plugin, zero code-gen, works with any AGP version

### 2. `file_picker` Gradle/AGP version wars
- **Problem:** `file_picker` compiled against `compileSdk 34` while other plugins required 36. Generated `GeneratedPluginRegistrant.java` kept referencing stale classes.
- **Fix:** Replaced entirely with native Android `Intent.ACTION_OPEN_DOCUMENT` via `MethodChannel`

### 3. Flutter SDK version mismatch
- **Problem:** Flutter 3.44.1 pre-release caused Dart SDK constraint conflicts
- **Fix:** Used `any` constraints on compatible packages, `>=3.5.0 <4.0.0` in pubspec

### 4. PDF library iterations
- Tried `pdfx` → unnecessary indirection
- Settled on `flutter_pdfview` directly (Apache 2.0, 2M+ downloads)
- Added `syncfusion_flutter_pdf` for text extraction only

### 5. `flutter_pdfview` + `syncfusion_flutter_pdf` name clash
- **Problem:** Both export a class called `PdfDocument`
- **Fix:** Import syncfusion with a prefix: `import 'package:syncfusion_flutter_pdf/pdf.dart' as sync;`

### 6. GitHub authentication for server pushes
- **Problem:** Fine-grained PATs didn't work; classic tokens expired
- **Fix:** SSH Ed25519 key scoped to this repo only — no expiration, revocable with one click

### 7. Android package name mismatch
- **Problem:** Firebase registered with `com.vocabreader.ai_vocab_builder` but build.gradle had `com.aivocabbuilder.ai_vocab_builder`
- **Fix:** Renamed namespace + applicationId + moved Kotlin source directory
